# E2 SFT 命令清单（LLaMA-Factory，复制粘贴就能跑）

> 前提：项目已上传到 `/root/autodl-tmp/rtl-rlvr/`，模型已下载到
> `/root/autodl-tmp/models/Qwen2.5-Coder-3B-Instruct`（见 RUNBOOK §4）。
> 所有命令在 GPU 实例上执行；`llamafactory` 是独立 conda 环境（保护 veRL 环境不被降级）。

## 1. 数据准备（AI 已生成的 jsonl 无需重跑，校验一下即可）

```bash
cd /root/autodl-tmp/rtl-rlvr
python scripts/to_llamafactory.py --problems data/spec_set_50.jsonl --split train \
    --out data/sft/sft_alpaca.json
# 预期输出: [to_llamafactory] 40 条 → data/sft/sft_alpaca.json
# 可选：并入 VerilogEval train 题（更多数据，质量见 clean_data.py 说明）
python scripts/to_llamafactory.py --problems data/spec_set_50.jsonl \
    data/verilogeval_cleaned.jsonl --split train --out data/sft/sft_alpaca.json
```

## 2. 安装 LLaMA-Factory（独立环境；2026-09-20 实测路径，已装好无需重跑）

> 实测（坑全部踩过）：GitHub 走 gh-proxy 极慢 → 用 codeload tarball；
> PyPI 上无 llamafactory 包；清华源对部分包 403；阿里云 CDN 的 av 轮子
> 固定 375KB 卡死 → aria2 多连接破卡。最终方案：venv --system-site-packages
> 复用系统 torch 2.11 + 双镜像 + aria2 拉 av。已装到 /root/llamafactory-env，
> 源码在 /root/LLaMA-Factory。重建脚本：install_lf_v4.sh。

```bash
/root/llamafactory-env/bin/llamafactory-cli version   # 验证
```

## 3. 注册数据集

```bash
cp ~/LLaMA-Factory/data/dataset_info.json ~/LLaMA-Factory/data/dataset_info.json.bak
cp /root/autodl-tmp/rtl-rlvr/configs/sft/dataset_info.json ~/LLaMA-Factory/data/dataset_info.json
# 注意：注册文件里的 file_name 是绝对路径，若实例路径不同先改它
```

## 4. 训练（LoRA，rank 32，3 epochs）

```bash
cd /root/LLaMA-Factory
/root/llamafactory-env/bin/llamafactory-cli train \
    /root/autodl-tmp/rtl-rlvr/configs/sft/llamafactory_sft.yaml
# 数据量小（102 条），预期 5-15 分钟。训练完记下 loss 曲线末尾值。
```

## 5. 合并 LoRA → 评估模型

```bash
/root/llamafactory-env/bin/llamafactory-cli export \
    --model_name_or_path /root/autodl-tmp/models/Qwen2.5-Coder-3B-Instruct \
    --adapter_name_or_path /root/autodl-tmp/rtl-rlvr/checkpoints/sft/e2-lora \
    --template qwen \
    --finetuning_type lora \
    --export_dir /root/autodl-tmp/models/e2-sft-merged \
    --export_size 4 \
    --export_legacy_format false
```

## 6. E2 评估（与 E1 同一脚本同一采样）

```bash
cd /root/autodl-tmp/rtl-rlvr
python scripts/eval_rtl.py pipe --problems data/spec_set_50.jsonl \
    --model /root/autodl-tmp/models/e2-sft-merged --split eval --out-dir results/e2
```

## 保底方案（LLaMA-Factory 装不上时）

```bash
cd /root/autodl-tmp/rtl-rlvr
python scripts/sft_hf_fallback.py --problems data/spec_set_50.jsonl --split train \
    --base /root/autodl-tmp/models/Qwen2.5-Coder-3B-Instruct \

# 用 transformers+PEFT 的等价 LoRA SFT（rank 32）。work-log 里如实记录用了哪个。
```

## 已知口径说明（如实记录，不回避）

- LLaMA-Factory 的 qwen 模板自带 system 提示词文本可能与 GRPO 端硬编码的
  Qwen 默认 system 文本有细微差异 —— 两个阶段各自遵循自己的模板，格式学习
  不依赖 system 文本的逐字一致；E2/E3 对比不因此失效。
- 若 SFT 只用了自建 40 题（无 VerilogEval），work-log 注明「训练数据仅自建
  spec 集，数据规模受限」。
