# E4 RTL verifier 命令清单（可选阶段，时间不够就跳过）

> 定位：Code-R1 E7「learned verifier」方法的 RTL 版 —— 用双闸标注数据训 1.5B
> 模型预测 k/N，温度 + Platt 双校准，ECE 验收。E4 是矩阵里的可选项，不影响
> E1-E3 主线叙事。

## 1. 标注数据（用 E1/E2/E3 的评估采样）

```bash
cd /root/autodl-tmp/rtl-rlvr
# 每个模型的 completions 合并标注（一次判分可多个 --completions）
python scripts/annotate_samples.py --problems data/spec_set_50.jsonl \
    --completions results/e1/completions.jsonl \
    --completions results/e2/completions.jsonl \
    --completions results/e3/completions.jsonl \
    --out data/verifier/verifier_train.jsonl
# 预期: [annotate] k/N 分布: {(0, 4): ..., (4, 4): ...}
# ⚠ 若 k 全为 0 或全为 N（无信号），先扩数据来源，别硬训（静默降级教训）
```

## 2. 训练 + 校准（独立环境即可，1.5B 单卡 4090 够；~1-2h）

```bash
# 安装依赖（llamafactory 或 base 环境均可）
pip install scikit-learn datasets --index-url https://pypi.tuna.tsinghua.edu.cn/simple
python configs/verifier/train_rtl_verifier.py \
    --data data/verifier/verifier_train.jsonl \
    --out /root/autodl-tmp/rtl-rlvr/checkpoints/verifier/e4-verifier-1.5b
# 验收线: ECE(platt) < 0.05；std < 0.1 说明预测塌缩，如实报告
```

## 3. 用进 GRPO（软信号 R = Result + λ·V，E7 模式，可选延伸）

主从设计不变：主奖励永远是双闸执行结果，verifier 只是 λ=0.1 的辅助信号。
集成需要 verifier 服务进程（Code-R1 实例上有实测过的 `verifier_server.py`，
把 INSTR/路径换成本项目的即可），训练端加：

```bash
bash configs/grpo/run_grpo.sh \
    +reward.custom_reward_function.reward_kwargs.use_verifier=True \
    +reward.custom_reward_function.reward_kwargs.lambda_v=0.1
```

诚实纪律（E7 教训）：verifier 信号链路是「静默降级」高发区 —— 开训前先
smoke 打印 reward 分解（DEBUG_REWARD_FN=1），确认 verifier 项非恒 0；通过率
下降时优先降 λ。这一步成本高、收益未验证，主线（E1-E3）优先。
