# RTL-RLVR 实验全景：从基线到最终模型的每一步

> 本文档 = 项目唯一全景参考：每个实验的完整方案（起点/数据/训练配置/成本）
> + 评测结果（双口径切片）+ 决策链（结论如何引出下一个实验）。
> 评测口径：同脚本 eval_rtl.py、同采样（贪心 n=1）、pass@1。
> **主判据 = 未见题 50**（14 自建 eval + 36 VerilogEval eval，任何阶段均未进
> 训练）；全集口径（V2 98 含 62 训练题）为「分布内表现」并列报告。

## 二、实验逐格记录

### E1：零样本基线（¥3）

| 项 | 值 |
|---|---|
| 方案 | Qwen2.5-Coder-3B-Instruct，无训练，贪心解码 |
| 结果 | V2 全集 20.41% / 难题 9.68% / 简单 38.89% / 未见 50 = 34.00% |
| 结论 | 语法会（综合率 92%）、逻辑不会；FSM 全挂。分层指标的起点 |

### E2：SFT（参考实现数据，¥2）

| 项 | 值 |
|---|---|
| 方案 | 基座 + LoRA(32/64) SFT，102 条参考实现，3 epochs，43 秒训练 |
| 结果 | V2 全集 32.65% / 难题 12.90% / 简单 66.67% / **未见 56.00%** |
| 结论 | SFT 教语法+简单题（简单 +27.8pp）；FSM 仍 0——「SFT 教格式」 |

### E3：GRPO（二值奖励，¥10）

| 项 | 值 |
|---|---|
| 方案 | e2-sft-merged + GRPO 66 步（二值 0.1/1.1，n=4，kl 0.001，lr 1e-6） |
| 结果 | V2 全集 33.67% / 难题 14.52% / 简单 66.67% / **未见 60.00% ← 泛化冠军** |
| 结论 | RL 增量集中在功能（FSM 0→2/6 含未见题）——「RL 学功能」 |

### P0a：拆分奖励（¥9，负面结果）

| 项 | 值 |
|---|---|
| 方案 | 同 E3，唯一变量 = split_reward（综合+0.3/仿真+0.7） |
| 结果 | V2 全集 31.63% / 难题 11.48% / 未见 58.82%——全口径落败 |
| 结论 | **证伪**：「综合过仿真错」被抬成合格样本，削弱功能信号。二值优于分档 |

### P0b：二值 + n=8 + DAPO 组过滤（¥9）

| 项 | 值 |
|---|---|
| 方案 | 同 E3，变量 = n=8 + filter_groups（metric=acc） |
| 结果 | V2 全集 34.69% / **难题 19.67%（+5.2pp）** / 简单 59.46% / 未见 50.98% |
| 结论 | 难题特化配方；代价 = 简单题退化（全对组被过滤的 DAPO 副作用） |

### E3b：续训 132 步（对照，¥5，负面结果）

| 项 | 值 |
|---|---|
| 方案 | E3 续训 66→132 步 |
| 结果 | 训练集 reward 0.44→0.79，但泛化崩（60%→50% 量级） |
| 结论 | **94 题小数据 11 轮过拟合；66 步 = 最优停止点** |

### E5：teacher 蒸馏（数据源轴腿 1，采样 ¥3 + 训练 ¥2）

| 项 | 值 |
|---|---|
| 方案 | DeepSeek API 采样 102 训练题 × n=4（通过率 60.3%）→ 双闸过滤 → 基座 + SFT(151 条去重) |
| 结果 | V2 全集 35.71% / 难题 19.67% / 简单 62.16% / 未见 54.90% |
| 结论 | teacher 数据在难题上强（+6.8pp vs E2）；未见题略退（分布内强化） |

### E6：自举（数据源轴腿 2，采样 ¥9 + 训练 ¥2）

| 项 | 值 |
|---|---|
| 方案 | P0b 模型采样 102 × n=8（通过率 35.8%）→ 双闸过滤 → 基座 + SFT(138 条去重) |
| 结果 | V2 全集 33.67% / 难题 16.39% / 简单 62.16% / 未见 52.94% |
| 结论 | 自举有效但弱于 teacher（有效样本被去重砍 154 条）；未见题退化最多 |

### mix：三源混合（数据源轴第 4 格，¥2）

| 项 | 值 |
|---|---|
| 方案 | 基座 + SFT(参考 102 + teacher 151 + 自举 138 = 391 条) |
| 结果 | V2 全集 **37.76%** / 难题 **21.31%** / 简单 64.86% / 未见 56.86% |
| 结论 | **三源互补成立**——mix > 任何单源；数据轴胜者 |

### E7：DPO（对比轴，¥2 + 评估 ¥4）

| 项 | 值 |
|---|---|
| 方案 | mix 模型 + DPO(26 对：自举 16 + teacher 10，sigmoid β=0.1 + ftx 0.1，1 epoch) |
| 结果 | V2 全集 37.76%（不变）/ 未见 56.86%（不变）；152 全口径 43.42→44.74（+1.3pp 全在训练题） |
| 结论 | **未见题证伪**：26 对只够分布内强化。构对率低是瓶颈（teacher 中间态错误太少） |

### E8：最终模型（GRPO 收尾，¥15）

| 项 | 值 |
|---|---|
| 方案 | E7 模型 + GRPO 66 步（P0b 配方：二值 + n=8 + 组过滤） |
| 结果 | **V2 全集 50.00% / 难题 40.98%（vs E2 的 12.90%，3.2 倍）** / 简单 64.86% / 未见 54.90% |
| 结论 | 全管线在训练分布内大获全胜；未见题未超 E3——见第五节核心发现 |

## 四、决策链（每个结论如何引出下一步）

1. E1 低 + 分层诊断 → E2 教语法
2. E2 的 FSM 0% → E3 用执行奖励（RL 教功能）
3. E3 难题增量小 → 调研 → P0 配方轴（split 证伪 → n=8+过滤难题特化）
4. 数据匮乏 → E5/E6/mix 数据源三路（teacher/自举/互补）
5. mix 之上 → E7 DPO（构对数据在标注时顺手收集）
6. 全部胜者按 canonical 顺序（SFT→DPO→GRPO）组装 → E8

## 五、核心发现（面试主叙事）

**小数据下「分布内提升」与「泛化」脱钩**：
- 全管线（E8）把训练分布内表现推到 50.00%（难题 ×3.2）——管线本身是有效的
- 但未见题 50 上，泛化冠军是**最小管线 E3**（60.00%）——每一步数据扩张
  都是分布内强化、泛化中性或略负
- 若没有「未见题口径」（用户 2026-09-21 指出 DPO 增益来自训练题），整个
  项目会误报「管线越长越好」
- 与文献呼应：VeriRL 的 SbW（防遗忘加权）、DAPO 的全对组副作用、
  VeriContaminated 的数据污染警告——同一个问题的三个侧面
