## 一、摘要（一句话）

在 Qwen2.5-Coder-3B 上完成 VeriRL mini 复现 + 三轴消融：**SFT 教语法、
GRPO 教功能**，全管线把 V2 全集从 32.65% 推到 50.00%（难题 12.9%→41.0%，
3.2 倍）；同时用未见题口径揭示关键教训——**小数据下训练分布内的提升与
泛化脱钩，泛化最优 = 最小管线（SFT + 66 步 GRPO，未见题 60.0%）**。

## 三、三轴消融结论

1. **配方轴（GRPO 奖励设计）**：split 奖励（综合+0.3/仿真+0.7）证伪（全口径
   落败，FSM -19pp）；n=8 + DAPO 组过滤 = 难题特化配方（难题 +5.2pp，
   代价简单题退化——全对组被过滤的副作用）；66 步 = 最优停止点（132 步过拟合）。
2. **数据源轴（同起点同框架，唯一变量=数据来源）**：teacher 蒸馏 > 自举 >
   参考实现（难题 19.7/16.4/12.9）；三源互补（mix 37.76% > 任何单源）。
   但增益几乎全在训练分布内。
3. **对比轴（DPO）**：26 对偏好数据在未见题上零增量——小样本 DPO 证伪
   （分布内 +1.3pp）；构对率低是瓶颈（teacher 中间态错误太少）。
4. **顺序轴**：SFT → DPO → GRPO（调研背书 + 实证一致）。

## 四、为什么 E8 全集大涨但未见题回落（核心发现）

- E5/E6 数据（teacher/自举）来自训练题 → 模型学到「训练分布内的解法」；
  mix/DPO/二次 GRPO 沿此方向强化 → 训练题（含 62 道难题）从 12.9% 到 41.0%
- 未见题与训练题分布存在 gap（VerilogEval 编号难度排序 + 自建集风格差异）
  → 分布内强化不迁移，且可能轻微挤占泛化能力
- **教训**：小数据下「数据扩张 + 长管线」的收益是分布内的；泛化最优 =
   **最小管线**。与 VeriRL 的 SbW（防遗忘加权）动机、Code-R1 的
   「难度依赖」结论形成三方呼应
- 面试金句：「我用未见题口径测出了管线的真实泛化边界——数据扩张让模型
   更会做见过的题，但泛化冠军是最简单的 SFT+GRPO。这个发现比任何正面
   数字都值钱，因为它防止了过拟合被误报成进步。」

3. 口径修正：评估主判据从「全口径」修正为「未见题」——用户 2026-09-21

4. 局限：数据规模 ~250 条（VeriRL 的 1/300）；判分用参考 oracle（弱于真
   testbench）；3B 模型
