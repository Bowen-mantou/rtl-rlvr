## 六、结论写法（三段式，每段 2-3 句）

1. **事实**：只写表格里的数字，不解释。
2. **机制**：E2 涨的是格式/综合（SFT 教会语法与 module 结构）；E3 涨的是
   仿真通过（RL 用执行奖励逼出功能正确）；与 Code-R1 结论同构（执行奖励 vs
   信号难度依赖）。数字不显著时**如实说「增量微弱」并给出可能原因**
   （数据规模 40-143 题、训练 50 步、3B 模型容量）。
3. **面试叙事**：「我在代码项目里做的所有事，换了个语言重做一遍」——
   数据管线（spec→RTL 对齐清洗）、训练（LLaMA-Factory + veRL 全套）、
   评估（双闸 + 分层指标）、奖励（客观执行信号，无手写 PRM 风险）。

## 负面结果与局限（如实报告）
