# Work-Log：P0 配方消融（P0a 拆分奖励 / P0b n=8+组过滤）

- 日期：2026-09-21
- 实例 / 卡型：AutoDL A800 80GB
- 一句话目标：GRPO 奖励配方轴消融——E3 二值基线 vs 拆分奖励 vs 组大小+组过滤

## P0a：拆分奖励（split_reward = 综合+0.3 / 仿真+0.7）

| 项 | 值 |
|---|---|
| 起点 | e2-sft-merged（与 E3 一致） |
| 步数 | 66（与 E3 一致） |
| 唯一变量 | reward_kwargs.split_reward=True |
| 训练 reward | 末步 0.516 / 最高 0.669（注意量纲与 E3 不同，不可直接比） |

**结果（全口径落败，负面结果如实报告）**：

| 口径 | E3 二值 | P0a 拆分 | Δ |
|---|---|---|---|
| V2 全集 98 | 33.67% | 31.63% | -2.0pp |
| V2 难题(>47) | 14.52% | 11.48% | -3.0pp |
| 扩展集 50 | 60.00% | 58.82% | -1.2pp |
| FSM 6 题 | 33.33% | 14.29% | -19pp |

**结论**：拆分奖励证伪。机制解读：「综合过仿真错」的样本从 0.1 抬到 0.4，
变成组内「合格样本」，削弱了「仿真全过」的独特信号——模型满足于能综合，
不再向功能正确收敛。与 Code-R1「手写过程奖励失败」同构：**客观执行信号里，
二值对比优于过程分档**（至少在此数据规模/组大小下）。

## P0b：二值 + n=8 + DAPO 组过滤（完成）

**结果（152 题全量，与 E3 同口径切片）**：

| 口径 | E3 | P0b | Δ |
|---|---|---|---|
| V2 全集 98 | 33.67% | 34.69% | +1.0pp |
| V2 难题(>47) | 14.52% | 19.67% | **+5.2pp** |
| V2 简单(≤47) | 66.67% | 59.46% | -7.2pp |
| 扩展集 50 | 60.00% | 50.98% | -9.0pp |
| FSM 6 | 33.33% | 0.00% | -33pp |

训练 reward（同量纲可直比）：P0b 最高 0.725 / 末步 0.425 vs E3 0.537/0.444。

**结论**：组过滤+n=8 在难题上 +5.2pp 显著有效（配方假说成立），但 DAPO
动态采样的副作用显形——简单题「全对组」被过滤 → 梯度消失 → 能力退化
（调研预言的「被丢弃比例随策略变强而上升」）。**P0b = 难题特化配方，
E3 = 均衡配方**。全集微弱领先（+1.0pp）。
**后续用法**：E6 自举采样用 P0b 模型（难题特化 → 难题正样本率更高），
自举数据回炉到均衡模型上补难题短板——配方轴与数据轴交汇。

| 项 | 值 |
|---|---|
| 起点 | e2-sft-merged（同） |
| 奖励 | 二值（同 E3；split 证伪后回归） |
| 组大小 | n=8（E3 的 2 倍） |
| 组过滤 | algorithm.filter_groups（metric=acc——veRL 契约：float 返回自动写 reward_extra_info["acc"]） |
| 步时 | ~100s/步（n=8 生成翻倍 + 零信号组重采样） |

**踩坑记录**：
1. `filter_groups.metric=score` 崩（本版 veRL 对 float 返回只写 `acc` 键）
2. run_p0b.sh CRLF 坑（Python 改 .sh 违反 PITFALLS 红线，Edit 工具重写修复）
3. 磁盘两次写满（P0a ckpt + 基座重下）→ 清理 P0a ckpt/p0a-final/基座

## 判据与决策门

- P0b vs E3 同口径全量评估（152 题），主看难题 split + FSM
- P0b 有效 → 配方轴胜者 = P0b；无效 → 配方轴收敛到 E3 二值，
  主攻方向转数据轴 E6（自举，on-policy 蒸馏）
